# Task 5 - Student Management System

## Description
The Student Management System is a Java-based
application used to manage student information.

It allows users to add, edit, remove, search,
and display student records.

The application uses Student and StudentManager
classes to organize and manage student details.

## Features
- Add new student records.
- Edit student information.
- Remove student records.
- Search for students.
- Display all student records.
- Store student information in a file or database.
- Validate student input.

## Technologies Used
- Java
- Classes and Objects
- ArrayList or Collections
- File Handling
- Scanner Class
- OOP Concepts
