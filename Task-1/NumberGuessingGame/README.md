# Task 1 - Number Guessing Game

## Description
The Number Guessing Game is a Java-based console
application in which the computer generates a
random number between 1 and 100.

The user needs to guess the correct number.
The application provides hints such as Too High
or Too Low until the correct number is guessed.

## Features
- Generates a random number between 1 and 100.
- Accepts user guesses.
- Provides Too High and Too Low hints.
- Congratulates the user after a correct guess.
- Limits the number of attempts.
- Supports multiple rounds.
- Tracks the user's score.

## Technologies Used
- Java
- Scanner Class
- Random Class
- Loops
- Conditional Statements
